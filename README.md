# Takamiya MS 23: a provisional machine-readable transcription of the *Piers Plowman* text

[![DOI](https://zenodo.org/badge/869194077.svg)](https://doi.org/10.5281/zenodo.13955351)

Edited by Ian Cornelius and J. Eric Ensley

Paul A. Broyles, technical co-editor

## About this repository

This repository contains a provisional, machine-readable transcription of the text of *Piers Plowman* in New Haven, Beinecke Library, Takamiya MS 23.
Other contents are:

- `takamiya-23.rng`, `validatory.py`: A schema and Python script for validation of the transcription file
- `documentation.md`, `config/`, `bibl/`: Source files for the [technical introduction to the transcription](https://github.com/icornelius/s-takamiya-23/releases/latest/download/documentation.pdf).
- `.github`: A GitHub Action workflow to build and release the technical introduction
- `LICENSE`: A license
